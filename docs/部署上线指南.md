# 部署上线指南（每日定时无人值守运行）

> 目标：让本项目在一台常驻服务器上每日定时自动运行，无需人工干预。
> 决策日期：2026-09-30

## 一、背景与目标

现在系统靠本机手动运行，核心流程（抓取 → LLM 分析 → 写回 Google Sheets）已稳定，
最近两次全量运行成功率 100%。要改成每日定时无人值守，需先清掉几个阻碍。

## 二、上线前阻碍与决策

| # | 阻碍 | 决策 |
|---|------|------|
| 1 | Google OAuth 每约 12 天失效（`invalid_grant`），失效后 `run_local_server` 会弹浏览器卡住等人授权 | **改用 Service Account**（永不过期、零交互）；`run_local_server` 加保护，无桌面时报错退出而非卡住 |
| 2 | 默认有头浏览器，无桌面环境跑不了 | 上 **AWS EC2（Ubuntu）**，用 **xvfb 虚拟显示器**跑有头 Chrome，尽量保住反爬成功率 |
| 3 | 网络/网关故障会把当天所有行标 `Error`、之后不再重试 | 暂不改（用户判断非阻塞）；后续可区分基础设施故障 vs 页面抓不到 |
| 4 | 写回是整表覆盖，会踩人工编辑 | 用户方案：约定运行时段组织内不编辑表格 |
| 5 | 无防重叠锁、无告警 | 后续设置 |
| 9 | 机房 IP 被反爬拦（findaphd 类硬站） | **暂不上代理**，先用 AWS IP 直跑，观察难站点掉多少再决定 |

（6 成本、7 可复现、8 日志轮转：用户判断暂不处理。）

## 四、AWS 开 EC2（用户操作，step by step）

### 4.1 创建实例
1. 登录 https://console.aws.amazon.com ，**先在右上角选好 Region**（如 Asia Pacific (Tokyo) `ap-northeast-1` / (Singapore) `ap-southeast-1`），选组织允许、离得近的
2. 搜索进入 **EC2** → 左侧 **Instances** → **Launch instances**
3. 填写：
   - Name：`gisource-vm`
   - Application and OS Images (AMI)：**Ubuntu Server 24.04 LTS**（Canonical 官方，架构选 64-bit x86）
   - Instance type：**t3.medium**（2 vCPU/4GB）起步；内存吃紧可选 **t3.large**（8GB）
   - Key pair：**Create new key pair** → 类型 RSA、格式 `.pem` → 创建时**下载 `.pem` 私钥并妥善保存**（唯一登录凭证，丢了进不去）
   - Network settings：勾 **Allow SSH traffic from** → 建议改成 **My IP**（只放行你的 IP 连 22，更安全）；确认 **Auto-assign public IP** 为 Enable
   - Configure storage：**32 GiB gp3**
4. 右侧 **Launch instance** → 等实例状态变 Running

### 4.2 连接实例
- 实例详情页记下 **Public IPv4 address**
- 本机终端：`ssh -i 路径/你的私钥.pem ubuntu@<PublicIP>`
  （Ubuntu AMI 默认用户名是 **ubuntu**；Windows 私钥权限报错时用 PowerShell 收紧 `.pem` 的 ACL，或用 Git Bash/WSL）

### 4.3 把项目搬上去
- 方式一：`git clone` 仓库到 VM
- 方式二：`scp -i 私钥.pem -r 本地目录 azureuser@<IP>:~/`
- 注意：`keys/`、`cache/`、`logs/`、`llm_logs/`、`text_info.xlsx` 都被 `.gitignore` 忽略，
  git clone 不会带过去，需单独传（尤其 `keys/` 里的密钥和 API key）

## 五、VM 环境配置（Claude 提供脚本，用户执行）
- 运行 `setup_ubuntu.sh`（待 Claude 编写）：装 Python 3.11 / Chrome / Tesseract / Node / xvfb + 依赖

## 六、Google Service Account（用户操作）
1. Google Cloud Console → 目标项目 → IAM & Admin → Service Accounts → Create
2. 建好后 → Keys → Add key → JSON → 下载
3. 打开目标表格 → Share → 把服务账号邮箱（`xxx@项目.iam.gserviceaccount.com`）加为 **Editor**
4. 若表在机构 Workspace 且禁止外部共享导致共享失败 → 改走「发布 OAuth 同意屏幕到生产状态」方案

## 七、定时运行
- Claude 提供 systemd timer 或 crontab 配置，每日定时触发 `run.sh`
- 先常开 EC2；后续可用 EventBridge Scheduler 在跑前开机、跑后关机省钱
  （注意：EC2 停机再开公网 IP 会变，若要固定 IP 需分配 **Elastic IP**）

## 八、上线后观察项
- 难站点（findaphd 类）在 AWS IP 下的失败率 → 决定要不要上代理
- 每日运行成功率、token/成本
- 日志增长（后续加轮转）
